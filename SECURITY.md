# Security policy

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/nathanmcnulty/azd-gui/security/advisories/new)
to report suspected vulnerabilities privately. You need a GitHub account to
submit a report.

Include the affected platform and version, reproducible behavior, expected
security boundary, and suggested mitigation when available. Treat exposed
credentials or signing material as compromised and rotate or revoke them before
reporting.

## Supported versions

Security fixes are prioritized for the current main branch and the next Windows
11 x64 beta. The published 0.1.0 alpha is a preview. Older builds receive
best-effort support.

## Response targets

The sole maintainer aims to acknowledge private reports within 7 calendar days
and provide initial triage or next steps within 14 calendar days. These targets
are best effort, with no guaranteed emergency coverage or remediation date.

## Safe disclosure

Keep vulnerability details private while the maintainer assesses impact and
coordinates a fix, mitigation, or disclosure decision. Keep tokens, signing
material and configuration, tenant identifiers, local paths, and sensitive
deployment output out of public issues, pull requests, and release material.
