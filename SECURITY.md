# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories
for this repository. Do not open a public issue containing tokens, signing
configuration, tenant identifiers, local paths, or sensitive deployment output.

Include the affected platform and version, reproducible behavior, expected
security boundary, and suggested mitigation when available. Treat exposed
credentials or signing material as compromised and rotate or revoke them before
reporting.

This project is maintained on a best-effort basis by a single maintainer.
